# Справочник карт maps2 (Big Book of Battle Mats style)

26 фэнтези-карт для боевых и социальных столкновений в стиле [The Big Book of Battle Mats](https://www.lokebattlemats.com/bigbook.html).  
Все карты в папке `maps2/`.  
Формат: топ-даун с сеткой для миниатюр (1 дюйм).

## Печать

Для печати в формате А4 (210×297 мм) или А3 (297×420 мм) при необходимости измените размер изображений в графическом редакторе. Рекомендуемое разрешение: 150–300 DPI.
