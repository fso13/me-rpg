# EZY-system — Сайт правил

Статический сайт с правилами EZY-system, включая базовые модули, модуль заклинаний и фэнтези-модули.

## Структура

- **index.html** — главная, обзор системы
- **core.html** — ядро системы (броски 2d6, критические результаты)
- **modules.html** — 11 модулей EZY (характеристики, навыки, броня, оружие и т.д.)
- **combat.html** — бой (инициатива, дальний/ближний бой, травмы)
- **spells.html** — модуль заклинаний (школы магии, мана, примеры заклинаний)
- **fantasy.html** — фэнтези-модули (расы, профессии, Волновое пространство, артефакты)

## Запуск

Открой `index.html` в браузере или используй локальный сервер:

```bash
# Python
python -m http.server 8080

# Node.js (npx)
npx serve .
```

Затем открой http://localhost:8080

## Дополнительные модули

### Модуль заклинаний
- Школы магии (Огонь, Лёд, Молния, Исцеление, Защита, Иллюзия, Некромантия, Призыв)
- Ресурс мана, круги заклинаний
- Примеры: Огненная стрела, Огненный шар, Лечение ран, Щит, Молния
- Связь с Осознанностью (Волновое пространство)

### Фэнтези-модули
- Волновое пространство в фэнтези (магия как энергия мира)
- Расы: Дворф, Эльф, Полурослик, Орк, Полуэльф
- Профессии: Воин, Маг, Жрец, Плут, Ремесленник, Охотник
- Артефакты и реликвии
- Элементали, нежить
- Таблицы для генерации
