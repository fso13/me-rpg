Модуль Skyrim для EZY-system

Модуль для игр в сеттинге The Elder Scrolls — Тамриэль, Скайрим и соседние провинции. Использует лор и механики вселенной Elder Scrolls.

Заклинания (5 школ магии)

Разрушение: Пламя, Искры, Мороз, Огненная стрела, Огненный шар, Цепная молния…

Восстановление: Лечение ран, Исцеление, Отпугивание нежити, Священный свет…

Изменение: Дубовая плоть, Определение жизни, Паралич, Телекинез…

Иллюзии: Успокоение, Страх, Невидимость, Маскировка…

Колдовство: Призыв фамилиара, Призыв атронаха, Призыв дреморы…

Оружие по материалам

Железо → Сталь → Эльфийское → Дварфское → Оркское → Эбонитовое → Стекло → Даэдрическое

Урон растёт с материалом: железный меч 1d6, даэдрический 1d10. СКА: кинжалы 3–4, мечи 2, двуручные 1.

Броня по материалам

Лёгкая: Кожа (ОС 10) → Эльфийская (12) → Стеклянная (14) → Чешуя дракона (16)

Тяжёлая: Железо (13) → Сталь (14) → Дварфская (15) → Оркская (16) → Эбонит (17) → Даэдрическая (18)

Кузнечное дело

Навыки: Стальное → Дварфское/Эльфийское → Оркское/Продвинутые → Эбонитовое/Стеклянное → Даэдрическое/Драконье

Улучшение: Обычное → Тонкое (+1) → Превосходное (+2) → Изысканное (+3) → Безупречное (+4) → Эпическое (+5) → Легендарное (+6)

Проверка 2d6 + Техника + Кузнечное дело против СЛ.

Зачарование и алхимия

Зачарование: Камни душ (малый, обычный, большой, великий). Зачарования на оружие (поглощение здоровья/маны, огонь, мороз) и броню (+ПЗ, +ОМ, сопротивление).

Алхимия: Зелья лечения, маны, выносливости; яды; сопротивления стихиям.

Крики (Ту'ум) и камни предков

Опционально. Крики: Неодолимая сила, Огненное дыхание, Морозное дыхание, Стальная плоть, Призыв дракона.

Камни: Воин (+20% урона), Маг (−10% ОМ), Вор (+25% скрытность), Леди (+10% восстановление).
